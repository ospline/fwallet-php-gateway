Fwallet Payment Gateway - PHP Integration Kit 🚀(English below / নিচে বাংলায় দেওয়া আছে)🇬🇧 English DocumentationWelcome to the official Fwallet Payment Gateway open-source PHP integration kit! This lightweight, secure, and ready-to-use template helps developers quickly integrate Fwallet into any custom PHP website.✨ Features🔒 Secure API Integration: Server-side API calls using PHP cURL to ensure your Secret API Key is never exposed to the frontend.📱 App-Like Mobile Friendly UI: A beautifully crafted, responsive card layout featuring a vibrant mix of colors (Red, Blue, Green, Pink, Black, and White).🔔 Custom Modals & Alerts: Strictly avoids default browser alert() or prompt(). Uses 100% custom-designed HTML/CSS modals for an elevated and seamless user experience.💾 1-Click Backup & Restore: Built-in Export/Import system. Easily download your plugin/system database and settings as a JSON file, and restore them instantly via file upload.⚡ Plug & Play: Single-file architecture for rapid deployment and testing.⚙️ RequirementsPHP 7.4 or higherPHP cURL extension enabledA local or live server environment (XAMPP, Laragon, cPanel, etc.)🚀 Installation & SetupClone or Download this repository.Place the fwallet_integration.php file inside your web server directory (e.g., htdocs for XAMPP, www for WAMP/MAMP, or your live server's public_html).Open your browser and navigate to the file (e.g., http://localhost/your-folder/fwallet_integration.php).🛠️ How to UseAPI Configuration (Settings Tab):Go to your Fwallet Merchant Dashboard and copy your Secret API Key.Open the UI, go to the Settings tab.Enter your Secret API Key, Success URL, and Cancel URL, then click Save.Making a Payment (Checkout Tab):The frontend provides a beautifully designed "Pay Now" interface.When a customer enters an amount (minimum 10 BDT) and clicks pay, the PHP backend securely sends a POST request to the Fwallet API.The system automatically redirects the customer to the secure Fwallet checkout page.Backup and Restore (Backup Tab):Export: Click the "Export" button to instantly download your configuration settings as a .json file.Import: Select your previously saved .json file and click "Import" to instantly restore your configuration.🛡️ Security GuidelinesNever expose your API Key in JavaScript or HTML files.All API requests must be routed through the server (PHP).Always verify transactions on your backend via Webhook/IPN before delivering the product or service.🇧🇩 বাংলায় ডকুমেন্টেশনঅফিসিয়াল Fwallet Payment Gateway ওপেন-সোর্স PHP ইন্টিগ্রেশন কিট-এ আপনাকে স্বাগতম! এই লাইটওয়েট, সুরক্ষিত এবং রেডি-টু-ইউজ টেমপ্লেটটি ব্যবহার করে ডেভেলপাররা খুব সহজেই যেকোনো কাস্টম PHP ওয়েবসাইটে Fwallet যুক্ত করতে পারবেন।✨ ফিচারসমূহ🔒 সুরক্ষিত API ইন্টিগ্রেশন: PHP cURL ব্যবহার করে সার্ভার-সাইড API কল, যার ফলে আপনার Secret API Key কখনোই ফ্রন্টএন্ডে বা ইউজারের ব্রাউজারে প্রকাশ পায় না।📱 অ্যাপ-লাইক মোবাইল ফ্রেন্ডলি UI: লাল, নীল, সবুজ, পিঙ্ক, কালো এবং সাদা রঙের দারুণ মিশ্রণে তৈরি একটি চমৎকার ও রেসপন্সিভ কার্ড লেআউট।🔔 কাস্টম মডাল ও অ্যালার্ট: ব্রাউজারের ডিফল্ট alert() বা prompt() ফাংশন ব্যবহার করা হয়নি। এর বদলে শতভাগ কাস্টম ডিজাইন করা HTML/CSS মডাল ব্যবহার করা হয়েছে।💾 ১-ক্লিক ব্যাকআপ এবং রিস্টোর: বিল্ট-ইন এক্সপোর্ট/ইমপোর্ট সিস্টেম। মাত্র এক ক্লিকে আপনার সেটিংস একটি JSON ফাইল হিসেবে ডাউনলোড করুন এবং ফাইল আপলোডের মাধ্যমে সহজেই সেটি রিস্টোর করুন।⚡ প্লাগ অ্যান্ড প্লে: দ্রুত টেস্টিং এবং ডিপ্লয়মেন্টের জন্য একটিমাত্র ফাইলে (Single-file) সম্পূর্ণ সিস্টেম তৈরি করা হয়েছে।⚙️ যা যা প্রয়োজনPHP 7.4 বা তার ওপরের ভার্সনPHP cURL এক্সটেনশন চালু থাকতে হবেএকটি লোকাল বা লাইভ সার্ভার পরিবেশ (যেমন: XAMPP, Laragon, cPanel ইত্যাদি)🚀 ইনস্টলেশন ও সেটআপ১. এই রিপোজিটরিটি Clone বা Download করুন।২. fwallet_integration.php ফাইলটি আপনার ওয়েব সার্ভারের ডিরেক্টরিতে রাখুন (যেমন: XAMPP-এর ক্ষেত্রে htdocs, বা লাইভ সার্ভারের ক্ষেত্রে public_html)।৩. ব্রাউজার ওপেন করে ফাইলের লিংকে যান (যেমন: http://localhost/your-folder/fwallet_integration.php)।🛠️ কীভাবে ব্যবহার করবেন১. API কনফিগারেশন (Settings Tab):প্রথমে আপনার Fwallet মার্চেন্ট ড্যাশবোর্ড থেকে Secret API Key কপি করুন।স্ক্রিনের Settings ট্যাবে যান।আপনার Secret API Key, Success URL এবং Cancel URL দিয়ে সেভ করুন।২. পেমেন্ট গ্রহণ (Checkout Tab):চেকআউট পেজে একটি সুন্দর "Pay Now" ইন্টারফেস দেওয়া আছে।কাস্টমার যখন একটি অ্যামাউন্ট (সর্বনিম্ন ১০ টাকা) লিখে পেমেন্ট করতে চাইবে, তখন PHP ব্যাকএন্ড নিরাপদে Fwallet API-তে একটি POST রিকোয়েস্ট পাঠাবে।এরপর সিস্টেমটি অটোমেটিক কাস্টমারকে Fwallet-এর নিরাপদ চেকআউট পেজে রিডাইরেক্ট করে দেবে।৩. ব্যাকআপ ও রিস্টোর (Backup Tab):এক্সপোর্ট (Export): বাটনে ক্লিক করে আপনার সেটিংসগুলো একটি .json ফাইল হিসেবে ডাউনলোড করে ব্যাকআপ রাখুন।ইমপোর্ট (Import): আগে সেভ করে রাখা .json ফাইলটি সিলেক্ট করে আপলোড করুন, আপনার পুরোনো সেটিংস সাথে সাথেই রিস্টোর হয়ে যাবে।🛡️ সিকিউরিটি গাইডলাইনকখনোই আপনার API Key কোনো JavaScript বা HTML ফাইলে রাখবেন না।API রিকোয়েস্ট সবসময় সার্ভার (PHP) থেকে করতে হবে।কাস্টমারকে প্রোডাক্ট বা সার্ভিস দেওয়ার আগে অবশ্যই ব্যাকএন্ডে (Webhook/IPN-এর মাধ্যমে) ট্রানজেকশনটি যাচাই (Verify) করে নেবেন।📄 LicenseThis project is licensed under the MIT License.
